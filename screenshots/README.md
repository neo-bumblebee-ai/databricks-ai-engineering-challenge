\# Screenshots



This folder contains evidence artifacts from key days (UI screenshots, results, MLflow runs, governance screens, and outputs used for documentation).



Subfolders are organized by day (e.g., `day12`, `day13`, `day14`) and typically include:

\- Job/workflow execution screenshots

\- MLflow experiment run comparisons

\- Unity Catalog governance screens

\- Genie or AI-assisted analytics examples

\- Output validation snapshots
